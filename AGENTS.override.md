# BotLab project continuity

Read the root `AGENTS.md` when present and preserve its project-context instructions. That generated file is read-only. All files under `sources/` are read-only synced reference material: do not edit, rename, move or delete them.

Before project work, read `docs/session-workflow.md` and `docs/next-steps.md`. Use the latter as the single current task and idea register across all BotLab areas; detailed plans retain specifications and historical evidence.

Capture relevant ideas, decisions and blockers during work, even when outside the current increment. Preserve task IDs and distinguish user requests, assistant proposals and historical items needing review. Recording an idea does not authorize its implementation or external actions.

Before ending a work session, update affected entries and the resume point with the result, meaningful verification, unresolved work and a concrete next action. Mark tasks complete only when their acceptance criteria are met. Do not rewrite the register for conversations that introduce no project change.

BotLab is educational: prioritize understandable actions, observable outcomes and progressive learning. Preserve existing workspace changes and consult current evidence before redoing historical tasks.

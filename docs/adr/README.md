# Architecture Decision Records

This folder records BotLab architecture decisions that should remain easy to find as the system grows.

## Records

- [0001: Keep editor, runtime, adapter, and simulator boundaries separate](0001-architecture-boundaries.md)

## Template

New records should use this shape:

```md
# ADR N: Title

## Status

Accepted | Proposed | Superseded

## Context

What pressure or question led to the decision?

## Decision

What are we choosing?

## Consequences

What does this make easier, harder, or more explicit?
```
